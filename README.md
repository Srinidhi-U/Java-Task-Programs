# Java Task Programs

A collection of 12 beginner-level Java programs covering loops, conditions, number logic, strings, and patterns.

## Programs

1. Pattern1 - Hollow Square Pattern
2. Pattern2 - Increasing Triangle Pattern
3. Sum - Sum of 1 to 10
4. Primesum - First 10 Prime Numbers
5. Primenumber - Check Prime Number
6. Prime - Prime Numbers from 1 to 100
7. Palindrome - Palindrome String
8. Largest - Largest of Three Numbers
9. Fibonacci - Fibonacci Series
10. Factorial - Factorial of a Number
11. EvenOdd - Even or Odd
12. Armstrong - Armstrong Number
